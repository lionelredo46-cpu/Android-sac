# Dossier AFRAM — portail étudiant

Ce dossier rassemble une recherche publique sur l’Académie Franco-Américaine de Management (AFRAM), établissement privé d’enseignement supérieur situé à Libreville, Gabon.

## Contenu

- `rapport-afram.md` : rapport de recherche principal, avec formations, admissions, campus, salles, équipements, contacts, limites et références.
- `rapport-afram.pdf` : version PDF du rapport.
- `data/` : données structurées de départ pour alimenter un portail étudiant.
- `assets/logo/` : logos publics téléchargés depuis le site officiel.
- `assets/brochures/` : brochures officielles accessibles publiquement.
- `assets/photos/` : quelques visuels publics du site officiel, utiles pour une maquette.
- `sources/` : instantanés HTML de pages officielles consultées.

## Important

Les informations publiques ne remplacent pas une validation par la direction ou la scolarité d’AFRAM. Les frais, les capacités de salles, les plans des campus, les pièces d’admission, les programmes détaillés et les calendriers doivent être confirmés avant une mise en production.
